# 技能规则抽取文档模板（抽取智能体必读）

> 本文件是抽取说明，不是最终交付物。按本模板为每个技能生成一份文档。
> 输出路径：`/workspace/study-docs/workflow/skill-rules/[skill-name].md`（文件名 = 技能目录名，全小写连字符）
> 源文件：`/workspace/.claude/skills/[skill-name]/SKILL.md`

## 抽取要求（六条铁律）

1. **完整读源**：SKILL.md 可能很长（200~700 行），用 offset/limit 分段读完，禁止只读开头。
2. **忠实抽取**：所有规则必须来自 SKILL.md 原文，禁止编造；保留原文关键细节（阈值、档位、裁决词、路径、格式约定、配置键）。
3. **祈使句改写**：把流程描述改写成可直接放进 AGENTS.md 的规则体（"必须……""禁止……""只有……才……""默认……，除非……"）。
4. **覆盖全阶段**：SKILL.md 的每个阶段/步骤至少对应一条规则，不得遗漏；SKILL.md 尾部的收尾要求（写 active.md、更新状态文件等）也要覆盖。
5. **术语保留**：关键术语保留英文原文并加中文说明（如 `Status: Blocked`、TR-ID、Accepted、PASS/CONCERNS/FAIL）。
6. **不改源文件**：只读 SKILL.md，只写目标文档。目标目录不存在时先创建。

## 文档模板（严格按此结构，X 替换为技能名）

```markdown
# X — 中文名（AGENTS.md 移植版）

> 来源：[SKILL.md](file:///workspace/.claude/skills/X/SKILL.md) ｜ 阶段：Phase N ｜ 移植目标：其它项目的 AGENTS.md / CLAUDE.md / skill 定义

## 1. 技能定位
- **命令**：`/X`
- **一句话职责**：……
- **触发前置**：运行前必须存在/满足的条件

## 2. 数据依赖
| 方向 | 内容 | 说明 |
|------|------|------|
| 读取 | 文件/配置键列表 | 为何读 |
| 产出 | 文件列表 | 路径 + 格式要点 |
| 派生智能体 | subagent_type 列表 | 各自职责；无则写"无，主会话直接执行" |

（如 SKILL.md 里有 resolve_config 配置解析，注明用到的配置键及档位影响；如实录，禁止臆测）

## 3. 核心规则（逐条编号 R1、R2……）
R1. ……（出处小节名）
R2. ……
（覆盖全部流程步骤、强制/禁止行为、条件分支、文件写入时机、协作协议要点）

## 4. 门禁与裁决（如适用）
- 门禁 ID / 审查者 / 裁决标准 / 取最严裁决规则
（SKILL.md 无门禁则省略本节）

## 5. 移植建议
- **可直接移植**：与游戏无关的通用规则（列 R 编号）
- **需替换概念**：GDD/ADR/引擎等游戏概念 → 移植时映射成什么
- **改写示例**：1-2 条"改写后即可进 AGENTS.md"的成品规则

## 6. 关联文档
- 上游技能 / 下游技能 / 引用的 docs 文件（没有则省略本节）
```

## 篇幅与质量

- 每份 80~220 行，完整优先，禁止凑长。
- 73 份文档风格必须一致（标题、节名、表格列名一字不差）。
