## 2. 建议的完整产品定位

买断制、单人离线可玩、原创修仙题材的俯视角生存 Roguelite。保留“移动躲避 + 自动攻击 + 构筑进化 + 风险取舍 + 局外备战”的辨识度。

用户已选择 Steam 1.0 **主要内容20小时以上**。本计划以正常难度首次主流程 **20–25小时**作为细化目标，全部解锁与挑战 **40–60小时**作为建议目标；后两项区间仍需试玩验证。主流程从新档到最终结局，包含战斗、章节目标、首次必要备战和推进；不计挂机、可选全收集、高难重刷、强制等候或失败重试来凑时长。

因此建议将原来单秘境循环升级为“8章连续推进的修仙试炼”，每章有引入、不同目标的多次试炼、关键抉择、章节Boss和新的能力/区域解锁。保留短局战斗，增加章节之间持续发展的目标。角色数量和技能组合提高重玩价值，本身不能证明主流程达到20小时。

首发支持 Windows x86_64、键鼠及正式支持矩阵内的手柄。建议简体中文和英文完整 UI/文本；如决定中文首发，必须在生产本地化资产前更改范围。macOS/Linux/Steam Deck 验证、移动端、微信小游戏另列后续版本。现有 macOS 开发测试不代表承诺发行 macOS 版。

建议 1.0 不纳入联机、开放世界、宗门经营、装备随机词条、广告、抽卡和持续活动系统。它们不是当前核心循环完整性的必要条件；增加任何一项均需重新评估生产计划。

### 20小时目标如何验证

细化后风险`SCOPE-TIME-01`：64次主线任务×13–15分钟≈13.9–16小时，加原先4–6小时章节推进预算为17.9–22小时，存在低于20小时的缺口；主动目标可能更快，局外时长也未有证据。不能据此宣布20小时内容已覆盖。若无法设计出足够有趣的推进，应增加有区别的主线任务或调整结构，不能延长动画、提高刷取门槛或依赖死亡重试。

在P2先验证两种目标机制，在P3完成一整章最终质量版本，测量每个任务及章节推进的有效时长和重复感，再决定其余7章的任务分配。全版验收至少8名首次完整通关玩家记录各章有效内容时间，报告中位数与范围；目标中位数≥20小时，且逐项扣除空闲/失败重试/可选挑战。若不达标，范围或体验设计仍需整改，不把数值目标直接写成商店承诺。
