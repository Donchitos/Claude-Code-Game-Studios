# ADR-0011 第三章潮汐与有限遭遇

状态：已实现并完成限定专项复核，限定 CAMPAIGN_GAMEPLAY_V1。

## Decision

保留8关ID与目标合同。第三章使用两张固定港口布局、有限分段增援，独立 CAMPAIGN_CHAPTER3_V1 快照标识。潮池以全局固定tick循环（预警90、涨水150、休潮210tick，错峰150）；水闸印按稳定target_id永久淹没对应潮池——休潮清零而非关闭，安全空间随拆印递减；全部由tick与completed_ids派生，不另存时钟，不删除已发预警。狩猎指定S1-E03，禁止全局首精英回退；其相位字段归潜地行为专用，阶段悟性改为阈值跨越事件（同一次伤害前后生命比对）发放，不存计数，恢复后不重发；阶段突破重置其攻击计时，打断回潜。Boss潮墙侧别由实体aim携带并左右交替，齿列间保留穿越窗口，几何参数数据化于tide_boss配置；每次发射前检查容量。

第三章沿用6+4递增悟性、3秒升级间隔。狩猎每次生命阶段突破8悟性，Boss每次18悟性；在玩家位置生成悟性球，跨两阶段累计发放，恢复后不重复领取。第二章通关（16关）已授予第三角色S1-C03；第三阶成长仍需24关（M03-08胜利时达到），第四阶40关；保留旧档既有等级。此次不改全游戏经济价格曲线，富余资源不是已关闭问题。

## Consequences

所有第三章持久权威仍归Arena/Mission/Profile；UI只读。新增内容hash不得接管旧chapter-two活动战斗，需旧包结束或用户明确放弃。两条新档1→24连续路线是自动证据，不是人类试玩或20小时验证。

## Acceptance Criteria

8关均自然通关；正确精英、三闸印淹没递进、护送中途事件、Boss交替潮墙和三阶段可观察。存档在阶段/升级/事件/目标/潮池相位边界可恢复且后续逐tick一致。第一/二章回归、终局失败写盘、chapter-two旧包兼容、实际新PCK GUI恢复通过。独立专项评审后冻结并交付。

## QA Test Cases

检查8关定义/初始快照、非法hunt ID/潮汐字段拒绝；逐一覆盖三闸印顺序与淹没中的预警；Boss侧别交替与容量满不部分发射、致死不新增攻击；中段机缘仅一次且恢复不跳过；真实1→24两路线及章间三阶拒绝、M03-08后三阶合法；每次恢复比较完整snapshot和后续帧。旧包活动档零写拒绝；包内GUI保存重建继续。新玩家试玩SKIPPED_BY_USER，battle_ready=false。

## 2026-09-17恢复与容量补充

Boss阶段及悟性在damage_enemy伤害边界同步提交，涵盖AI之后弹体/区域伤害跨阈值；不得以放宽快照phase断言规避合法快照误拒。阶段改变只重置下一轮冷却，不取消已发布预警。第三阶段整轮预检16个区域和12枚弹体，任一容量不足均不消耗侧别/攻击冷却；388/389/400弹池边界和自然跨阶段快照纳入专项。
