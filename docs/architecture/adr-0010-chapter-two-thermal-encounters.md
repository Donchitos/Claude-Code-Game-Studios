# ADR-0010 第二章热场与有限遭遇

状态：已实现并完成限定专项复核，限定 CAMPAIGN_GAMEPLAY_V1。

## Decision

保留8关ID与目标合同。第二章使用两张固定矿轨布局、有限分段增援，独立 CAMPAIGN_CHAPTER2_V1 快照标识。喷口以全局固定tick循环；控制器/燃芯管按稳定target_id关闭对应喷口，并移除未生效预警。自由顺序不重置剩余喷口时钟，避免无预警喷发。狩猎指定S1-E02，禁止全局首精英回退。炉工中段使用现有机缘冻结与结算；炉门状态由tick推导，不另存时钟。Boss每次增加阶段时重置攻击计时，保留已发出的完整预警，不删除伤害后重发；每轮发射前检查容量。

第二章沿用6+4递增悟性、3秒升级间隔。狩猎每次生命阶段突破8悟性，Boss每次18悟性；在玩家位置生成悟性球，跨两阶段累计发放，阶段记录恢复后不重复领取。真实第一章通关开放第二阶成长与第二角色，第三阶仍需24关；保留旧档既有等级。此次不改全游戏经济价格曲线，富余资源不是已关闭问题。

## Consequences

所有第二章持久权威仍归Arena/Mission/Profile；UI只读。新增内容hash不得接管旧G活动战斗，需旧包结束或用户明确放弃。两条新档1→16连续路线是自动证据，不是人类试玩或20小时验证。

## Acceptance Criteria

8关均自然通关；正确精英、三控制器/六自由顺序关闭、护送中途事件、Boss门窗和三阶段可观察。存档在阶段/升级/事件/目标/炉门边界可恢复且后续逐tick一致。第一章回归、终局失败写盘、G旧包兼容、实际新PCK GUI恢复通过。独立专项评审后冻结并交付。

## QA Test Cases

检查8关定义/初始快照、非法hunt ID/热场标签拒绝；逐一覆盖六管线顺序与关闭中的预警；门开关边界伤害比例、容量满不部分发射、致死不新增攻击；中段机缘仅一次且恢复不跳过；真实1→16两路线及章间二阶购买/三阶拒绝；每次恢复比较完整snapshot和后续帧。旧包活动档零写拒绝；包内GUI保存重建继续。新玩家试玩SKIPPED_BY_USER，battle_ready=false。
